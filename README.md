# 🌾 INAFC Campo — Portal e Aplicação para o Trabalhador Rural

O **INAFC Campo** é uma plataforma digital desenvolvida para apoiar trabalhadores e produtores rurais do município de Porto Murtinho - MS e região. O projeto visa facilitar o acesso a informações essenciais sobre clima, direitos trabalhistas, cotações agrícolas e canais de assistência direta, com uma interface intuitiva e responsiva.

---

## 🚀 Tecnologias Utilizadas

* **React** (v18+) — Biblioteca para construção de interfaces web
* **TypeScript** — Tipagem estática para maior segurança do código
* **Vite** — Ferramenta de build e servidor de desenvolvimento rápido
* **CSS3** — Estilização modular e responsiva

---

## 📱 Funcionalidades Principais

* **🚨 Central de Ajuda:** Acesso a suporte e canais de emergência rural.
* **📖 Direitos do Trabalhador:** Guia simplificado com orientações jurídicas e trabalhistas do setor agrícola.
* **🌤️ AgroTempo:** Monitoramento de temperatura, umidade, volume de chuva, vento e recomendações para o cultivo em Porto Murtinho.
* **📈 Cotações e Insumos:** Acompanhamento dos preços de referência (Soja, Milho, Boi Gordo).
* **📞 Contato e Assistência:** Canais diretos de atendimento e apoio da equipe extensionista.
